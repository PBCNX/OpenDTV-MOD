IT9308 driver  (PBCNX/it9308)

The IT930x USB bridge driver in this app is the clean-room project
PBCNX/it9308, MIT.

Vendored from a tagged release (see docs/IT9308-CORE.md for the pin and the sync rules):

    Bridge.java, It9308Device.java, Sequence.java, SignalStatus.java, Transport.java
    android/AndroidTsReader.java, android/AndroidTransport.java, android/UsbDeviceLike.java
    resources/it9308/sequence.bin   (the captured command sequence)

The classes carry PROVENANCE = "it9308-pbcnx" - a searchable attribution marker, not telemetry.

Not included from that project: firmware.bin, the IT930x bridge image extracted from the vendor
Android application. It is vendor firmware, not MIT, and is not distributed with this source.
