Bundles FFmpeg (libavcodec, libavutil, libswresample, libswscale), https://ffmpeg.org,
built with GPL options. Source code for the FFmpeg build is available from the NextLib repository.

Because this library is GPL-3.0, distributing OpenDTV with it means the combined app must be
made available under GPL-3.0 terms, including its source code.
