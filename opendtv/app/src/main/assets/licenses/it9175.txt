IT9175 driver  (PBCNX/it9175)

The IT9175 tuner path in this app IS the clean-room core published as PBCNX/it9175, MIT, release
v0.2.1. Vendored files (see docs/IT9175-CORE.md for the pin and the sync rules):

    ph/pbcnx/it9175/          Tuner, Tables, It9175Device, AfaCmd, AfaIo, Firmware, Status,
                              Transport, TsReader, Io
    ph/pbcnx/it9175/android/  AndroidTransport, AndroidTsReader

The core carries PROVENANCE = "it9175-pbcnx" - searchable attribution, not telemetry.

The firmware image the chip needs is NOT part of that project and is not covered by this licence:
it is vendor firmware, supplied by the user or bundled as a private asset in the beta
(assets/firmware/it9175-ite-v3046.bin, 9,036 B, sha256 451b09a4...c3575c). See the
"Firmware images" entry.
